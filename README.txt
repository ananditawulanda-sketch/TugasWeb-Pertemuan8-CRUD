# Tugas Rutin 8 - CRUD Inventaris

## Deskripsi

Aplikasi CRUD Inventaris dibuat menggunakan PHP Native, PDO, dan MySQL.
Aplikasi ini digunakan untuk mengelola data barang, kategori, dan supplier.

## Fitur

- Menampilkan data barang
- Menambahkan data barang
- Mengedit data barang
- Menghapus data barang
- Data kategori
- Data supplier
- Relasi tabel menggunakan Foreign Key
- Prepared Statement menggunakan PDO

## Teknologi

- PHP Native
- PDO
- MySQL
- XAMPP
- HTML
- CSS

## Cara Menjalankan

1. Aktifkan Apache dan MySQL pada XAMPP.
2. Letakkan folder project di dalam `htdocs`.
3. Buka phpMyAdmin.
4. Buat database dengan nama `db_inventaris`.
5. Import file `schema.sql`.
6. Buka aplikasi melalui browser:

   http://localhost/pertemuan-8/

## Database

Nama database:

`db_inventaris`

File database:

`schema.sql`
